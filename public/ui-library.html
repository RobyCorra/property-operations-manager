09 — Riepilogo interventi suggeriti

Alta priorità

  • •Touch target sotto 44px (bottoni, close, tabs)
  • •Testi 9px illeggibili su mobile
  • •Badge senza distinzione visiva per stato vuoto vs. critico
  • •Form input troppo piccoli per touch

Media priorità

  • •Palette colori non sistematizzata (amber vs orange)
  • •Tipografia senza scala coerente (troppi livelli)
  • •Card list senza info secondarie utili (orario, ospite)
  • •Empty state senza illustrazione/icona

Miglioramenti futuri

  • •Bottom tab bar al posto di hamburger menu
  • •KPI card con trend (freccia su/giù)
  • •Animazioni micro-interaction (spring, haptic)
  • •Dark mode con palette già definita
